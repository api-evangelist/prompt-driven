# Prompt Driven (PDD)

> Prompt-Driven Development (PDD) is a prompt-native programming system where .prompt files are the human-authored source language and traditional code (Python, TypeScript, Go, ...) is generated as an artifact. PDD ships as a single Python CLI, pdd-cli, plus a local web interface (PDD Cloud). Tagline: "The Last Programming Language." Backed by 500 Global.

## CLI (pdd)

The `pdd` binary drives the Define -> Generate -> Verify -> Test -> Update cycle.

- Setup: `pdd setup` (create ~/.pdd credentials), `pdd connect` (launch local UI)
- Agentic (implement GitHub issues): `pdd change <issue-url>`, `pdd bug <issue-url>`, `pdd fix <issue-url>`, `pdd split <target-file>`, `pdd generate <issue-url>`, `pdd test <issue-url>`
- Prompt workflow: `pdd sync` (full cycle), `pdd checkup` (prompt/story quality gates + coverage)
- Routing policy: use `pdd bug` then `pdd fix` for runtime symptoms; `pdd change` then `sync` for explicit spec/product changes.
